# Papan Peringkat Kehadiran (Attendance Leaderboard)

Plugin Blok untuk Moodle yang menampilkan papan peringkat kehadiran siswa berdasarkan data dari plugin Attendance.

## Fitur

- Menampilkan daftar peringkat siswa berdasarkan kehadiran
- Menghitung dan menampilkan poin kehadiran, jumlah hadir, terlambat, izin, dan tidak hadir
- Konfigurasi untuk menampilkan semua siswa atau hanya sejumlah siswa teratas
- Mendukung bahasa Inggris dan Indonesia

## Instalasi

1. Unduh atau clone repositori ini
2. Ekstrak ke direktori `blocks/attendanceleaderboard` di instalasi Moodle Anda
3. Kunjungi halaman notifikasi admin untuk menyelesaikan instalasi

## Persyaratan

- Moodle 4.0 atau yang lebih baru
- Plugin [Attendance](https://moodle.org/plugins/mod_attendance)

## Penggunaan

1. Aktifkan mode pengeditan di halaman kursus
2. Klik "Add a block" dan pilih "Papan Peringkat Kehadiran"
3. Konfigurasi blok sesuai kebutuhan

## Konfigurasi

- **Judul blok**: Ubah judul yang ditampilkan di blok
- **Tipe tampilan**: Pilih untuk menampilkan semua siswa atau hanya siswa teratas
- **Jumlah siswa yang ditampilkan**: Tentukan berapa banyak siswa yang akan ditampilkan jika Anda memilih untuk menampilkan siswa teratas
